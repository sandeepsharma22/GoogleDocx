# Google Docx

A real-time collaborative document editor built with Next.js 15, React 19, Clerk, Convex, and Liveblocks.

🌍 **Live Demo:** [https://google-docx-eight.vercel.app](https://google-docx-eight.vercel.app)

## Features

- **Real-time Collaboration:** Multiple users can edit the same document simultaneously, with live cursors and typing indicators (Liveblocks).
- **Authentication:** Secure user authentication and management (Clerk).
- **Database:** Real-time document storage and synchronization (Convex).
- **Modern UI:** Built with Tailwind CSS and Next.js 15 App Router.

## Tech Stack

- **Framework:** Next.js 15
- **Frontend:** React 19
- **Styling:** Tailwind CSS
- **Database:** Convex
- **Authentication:** Clerk
- **Collaboration:** Liveblocks
